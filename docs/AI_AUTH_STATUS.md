# Recheck 다중 AI 인증 구현과 검증 상태

**Recheck 0.1.6의 AI 연결 구현과 계정별 검증 범위입니다.** 2026-11-17의 새 연결 점검과 2026-11-16의 이전 버전 검증을 아래에 나눠 기록합니다. 버전 이름 대응은 [공개 이력](PUBLIC_HISTORY.md#공개-버전-이름-정리)을 참고하세요. 최종 실행본·게시 결과는 해당 릴리스와 [작업 기록](https://github.com/leekmny/Recheck/blob/main/docs/decisions/2026-11-17-embedded-login-work-log.md)을 따르며, 이전 버전의 결과를 새 실행 파일의 성공으로 계산하지 않습니다.

## 0.1.6 연결 화면 통합

- 공통 제공자 선택·키 발급 화면·내장 ChatGPT 표시·명시적 외부 브라우저 선택·보안 키 입력·실제 응답 검사 흐름을 구현했습니다.
- 로그인·키 발급은 외부 브라우저가 기본입니다. **로그인·키 발급 화면을 앱 안에서 열기**는 기본 해제이며, 체크하면 모든 제공자의 내장 표시를 선택할 수 있습니다. 최초 버튼은 **ChatGPT 로그인** 또는 **제공자 이름 + API 키 발급**입니다. 연결된 제공자는 **연결 상태 확인**으로 바뀌며 새 로그인·키 발급·응답 요청 없이 저장된 상태를 읽습니다.
- ChatGPT 계정·모델에 결합된 실제 검사 기록으로 재실행 시 상태를 복원하고 완료 화면을 유지합니다. 응답 확인·재로그인·로그아웃·다음 단계는 별도 동작으로 제공합니다.
- 실제 응답 proof 없이 기본 AI를 바꾸지 않으며 새 키 검사 실패 시 기존 키·기본 AI를 유지합니다. 취소·뒤늦은 신호·프로필 변경·브라우저 종료를 회귀 검사합니다.
- Google 내장 인증은 정책 제한을 설명하고 사용자가 기본 브라우저를 선택하도록 합니다. 내장 ChatGPT의 확인 가능한 로그인 화면에서는 Google 선택지를 숨기며, 계정 선택·다른 로그인 수단·외부 브라우저는 바꾸지 않습니다. ChatGPT 공식 시스템 브라우저 안내와 내장 호환 표시를 구분합니다.
- 진행 중 작업을 취소하는 **연결 중단**과 연결된 상태의 **연결 해제**를 구분합니다. 프로그램 비교에서는 준비된 AI 연결·모델 하나를 선택합니다. 여러 AI의 자동 병렬 요청은 구현하지 않았습니다.
- 최종 변경을 포함한 전체 소스·frozen EXE·공개 ZIP 검증은 별도로 확정합니다. 앞선 빌드의 통과를 최종 배포 완료로 대신하지 않습니다.

## 2026-11-17의 새 연결 점검

평소 사용하는 앱 데이터에서 ChatGPT 인증 자료, 외부 앱 사용 권한, 해당 모델의 실제 응답과 보호된 검사 기록 저장을 확인했습니다. 기본 응답과 JSON 검사는 통과했고 도구 호출 검사는 통과하지 않았습니다. 따라서 이 연결의 기본 설명 준비와 도구를 사용하는 추가 분석 준비를 구분합니다. 당시 기본 분석 AI는 ChatGPT로 선택되지 않은 상태였으며, 계정 연결이 준비됐다는 사실이 이번 분석의 AI 선택을 대신하지 않습니다.

후속 안전한 메타데이터 점검에서 Gemini API 키 연결 두 개 모두 현재 프로필에 결합된 실제 응답 검사 기록과 보호 저장을 확인했고, 그중 하나가 기본 AI로 선택돼 있었습니다. 반복 연결로 생긴 기존 항목은 삭제하거나 통합하지 않았습니다. 이는 현재 저장된 연결의 확인이며, 새 비교 화면의 전체 동작이나 최종 배포 검증과는 별개입니다. 아래 이전 버전의 고정 입력 설명 평가도 당시 범위로 따로 보존합니다.

앞선 화면 점검에서는 로그인 반복 시 초기화되는 UI와 완료 후 자동 이동을 확인해 수정했습니다. 당시 점검용 저장소에는 ChatGPT 인증·검사 기록이 없고, 화면에는 `invalid_grant` 안내가 남았습니다. 이후 정상 앱 데이터에서 확인한 새 연결과 다른 시점의 관찰입니다. 공식 절차에 맞춰 발급된 등록 ID를 유지한 새 인증을 한 번만 진행하는 복구도 추가했습니다. 이 결함이 당시 서버 거절의 유일한 원인이었다고 단정하지 않습니다.

무료 계정의 새 내장 연결·실제 추론은 미검증입니다. 2026-11-17에 확인한 [공식 도움말](https://help.openai.com/en/articles/20001542-using-your-chatgpt-plan-in-other-apps-and-sites)은 지원되는 오픈소스 도구를 모든 ChatGPT 사용자가 이용할 수 있다고 안내하지만, [개발자 빠른 시작](https://developers.openai.com/siwc/quickstart)은 적격 Plus·Pro 사용자를 명시합니다. 이 안내 차이나 `invalid_grant`만으로 모든 무료 계정의 이용 불가를 단정하거나 앱에서 요금제를 임의로 차단하지 않습니다. 실제 서버의 권한·모델·응답 결과로 판단합니다.

사용자는 무료 계정에서 현재 계정·워크스페이스·플랜의 필수 권한을 사용할 수 없다는 공식 안내를 봤고, 이후 외부 웹 로그인 자체는 성공했다고 보고했습니다. 앞선 점검에서는 앱에 새 인증이 저장됐는지 확인하지 못했으므로 그 웹 로그인 보고만으로 추론 성공을 판정하지 않았습니다. 이는 위의 후속 연결 점검과 구분합니다. ChatGPT에는 **외부 앱 사용 권한**이 필요하며, 무료 계정에서 권한 제한이 나오면 지원되는 플랜의 계정이나 다른 AI를 선택하도록 안내합니다. 앱이 업그레이드를 자동 진행하거나 정적 콜백 페이지에서 사용자의 실제 플랜을 추정하지 않습니다.

Google 내장 진행 실패도 앱의 선제 정책 차단과 Google 서버 오류 실측을 구분합니다. 상세 원인·공식 근거·재검토 조건은 [외부 기본값 결정](https://github.com/leekmny/Recheck/blob/main/docs/decisions/0006-external-browser-default.md)에 기록했습니다.

## 이전 버전에서 확인한 실제 계정 범위

| 연결 | 실제 확인 범위 |
| --- | --- |
| ChatGPT | 공식 앱 자체 OAuth 로그인·추론 권한·모델 목록·기본 응답·JSON·도구 호출과 왕복·보호된 검사 결과 저장 확인. 실제 할인 예제의 비교·GPT 설명·추가 분석·보고서 확인. |
| Ollama | 이전 배포본에서 gemma4:e4b와 Linux 예제 3종 비교 실측. 이번 변경에서는 기존 경로 회귀 검사. |
| OpenAI API 키 | 구현·모의 HTTP 회귀 검사. 실제 사용자 API 키 추론은 미검증. |
| Claude API | 구현·모의 HTTP 회귀 검사. 실제 키 추론은 미검증. Claude.ai 구독 로그인 미지원. |
| Gemini 3.5 Flash-Lite API 키 | 사용자 제공 키로 모델 목록·기본 응답·JSON·도구 호출 왕복·보호된 검사 결과 저장 확인. ELF 고정3입력의 비교 결과 설명 확인: 2일치·1차이, 입력100에서 원본900/변경본1000 차이를 근거와 대조 |
| Gemini 4 Hydrogen API 키 | 작은 기본 응답과 JSON·도구 왕복 확인. 최초 긴 nonce 기능검사는 출력256토큰에서 길이 초과로 실패하여 증거 저장·기본 선택을 적용하지 않음. 별도 후속 검증 필요 |
| Gemini Google Desktop OAuth | 구현·회귀 검사. 실제 Google OAuth 계정 추론 미검증 |
| OpenAI 호환 서버 | 구현·모의 HTTP 회귀 검사. 실제 개별 서버와 모델은 미검증. |

OAuth는 공식 동적 앱 등록·PKCE·loopback callback·JWT/JWKS와 nonce 검증을 사용합니다. 브라우저 승인은 사용자가 완료했고, 이후 앱 자체 계정 저장과 실제 추론을 확인했습니다. 다른 앱의 로그인 자료를 가져오지 않았습니다.

Gemini 설명의 첫 응답은 Markdown 코드 울타리를 포함해 JSON 검증에서 거절됐습니다. 허용된 업무 요청 예산 안에서 수정 응답을 받아 앱의 설명 스키마·근거 참조·실측 지표 불변 검사를 통과했습니다. 최초 실패와 수정 후 성공을 구분하며 모든 프로그램·입력·모델의 정확도로 일반화하지 않습니다. 깨끗한 다른 PC 설치나 Windows PE 실행 검증도 아닙니다.

무료 등급은 사용자가 프로젝트 화면에서 확인했습니다. API200·모델 목록·응답 성공만으로 무료 결제 상태나 남은 할당량을 독립 증명한 것은 아닙니다. 앱은 유료 프로젝트·모델로 자동 전환하지 않습니다. [Gemini 무료 연결 안내](GEMINI_FREE_SETUP.md)를 따르세요.

Gemini 스트림의 시작 이벤트에 이미 포함된 첫 텍스트가 후속 조립에서 사라지던 결함도 수정했습니다. JSON 앞부분·초기 응답·거절 상태를 보존하며 불완전 응답을 성공으로 바꾸지 않습니다.

실제 서비스 응답으로 두 가지 호환 문제를 재현했습니다. ChatGPT 모델 목록의 `models/slug/visibility` 형식을 읽도록 수정했고, 완료된 Responses 응답의 `incomplete_details: null`을 정상 처리합니다. 숨김 모델·잘못된 목록·불완전 응답은 정상 성공으로 처리하지 않습니다.

설정에는 보안 자료 참조만 저장합니다. Windows 현재 사용자 DPAPI 보호와 프로필·origin·인증 버전 결합을 유지합니다. 도구 경로 또는 PC 자원 설정 변경은 무관한 GPT 검증 자료를 지우지 않습니다. AI 프로필·모델·인증 결합이 달라지면 재사용하지 않습니다.

모델 목록 확인과 응답 생성 검사는 다릅니다. 기능 확인은 별도 최대 4회 요청이며, 비교 업무는 해석과 추가 분석 전체에서 최대 요청 예산을 공유합니다. 자동 HTTP 재전송은 없습니다. 연결 성공이 모든 분석의 성공 또는 AI 설명의 사실성을 보장하지는 않습니다.
