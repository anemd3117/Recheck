## 초기 기록 시점의 미검증과 제약

초기 기록 시점에는 실계정 승인·토큰 교환·실제 추론, frozen EXE, 다른 PC, 새 ZIP 공개 다운로드를 완료로 표시하지 않았다. 이후 확인은 아래에 추가한다. 사용자가 요청한 **잘 동작하면 배포** 조건은 실제 확인과 별도 배포 검사로 판단한다.

## 실제 화면 점검에서 추가된 수정

사용자는 로그인 버튼을 다시 누를 때 처음부터 시작하는 현상과 완료 표시가 바로 사라지는 현상을 보고했다. 기존 흐름은 다시 누를 때 진행 단계를 초기화했고, 완료 후에는 자동 도구 준비로 다른 화면으로 이동했다. 저장된 계정·검사 기록에 따른 상태 복원, 읽기 전용 연결 상태 확인, 별도 재로그인·응답 확인, 명시적인 다음 단계로 수정한다.

당시 점검용 저장소에는 ChatGPT 인증·응답 검사 기록이 없었고, 네이티브 화면에는 `invalid_grant`에 대응하는 안내가 남았다. 따라서 **저장에 성공한 토큰을 앱이 지웠다**고 결론내리지 않는다. 다음 실계정 점검에서는 민감정보 없는 단계·오류 코드 기록으로 승인·토큰 교환·저장의 경계를 확인한다.

사용자가 요청한 Google 로그인 선택지 숨김은 내장 공식 로그인 화면에만 제한해 구현했다. 합성 WebEngine 화면으로 다른 로그인 수단·계정 선택·SPA 전환 보존과 입력값 미접근을 검사했다. 공식 서비스의 실제 화면과 새 EXE 확인은 후속 점검으로 남긴다.

공식 인증 절차와 대조해 `invalid_grant` 뒤 발급된 등록 ID를 유지한 새 인증이 빠져 있음을 확인했다. 기존 코드를 재전송하지 않고 새 state·nonce·PKCE로 한 번만 복구하도록 보완한다. 같은 작업의 웹 창 교체가 작업 자체를 취소하던 경우도 실패 테스트로 재현한 뒤 수정했다. 이 계약 차이는 확인한 결함이며, 당시 실제 거절의 유일한 원인이라고 단정하지 않는다.

## 외부 기본값 변경과 단계별 확인

후속 사용자 요청으로 외부 브라우저를 기본값으로 바꾸고 모든 제공자의 내장 선택은 체크박스 해제로 유지했다. 공통·기존 Gemini 키 발급 버튼 모두 이 선택을 따르며 화면 순서는 추천 ChatGPT → Gemini 무료(API) → AI 계정 연결로 정리했다. Google의 상세 제한 근거와 관측·추정·미검증 구분은 [ADR-0006](0006-external-browser-default.md)에 추가했다. 같은 작업의 재승인에서는 임시 웹 프로필을 유지하고 이전 페이지·팝업·신호를 정리하도록 보완했다. 콜백 안내 페이지도 후속 요청으로 개선했다. 이 변경들을 포함한 새 소스·실행본 검증은 아래 이전 검사와 별도로 수행한다.

### 외부 기본값 변경 전 확인 기록

최신 소스 자동 검사는 `scripts/verify_source.py --output verification/embedded-login-production/final-source-checks-04`로 실행했다. Python 3.14.8에서 pytest **2,062 통과·1 건너뜀**, Node **7 통과**이며 합성 실제 WebEngine 검사도 활성화했다. Ruff·의존성 검사와 문서 13개·로컬 링크 94개 검사도 통과했다. 실행 중 소스·검사 입력의 불변성을 확인한 소스 식별자는 `2c8ecc743b57bf2073cfe0e4b0dc2b43c63459309eae8a413cb1ce80a6ea66b6`이다.

상태 유지·안전한 진단 기록·Google 선택지 표시·인증 복구에 대한 독립 검토를 완료했고, 검토 중 발견한 완료 직전 상태 변경 문제도 회귀 검사와 함께 수정했다. 새 frozen EXE·실계정·공개 배포 결과는 진행 중이며 이 자동 검사 결과로 대체하지 않는다.

### 외부 기본값·화면 순서·콜백 디자인 반영 후

후속 화면 검수로 AI 제공자 선택란에 위·아래 화살표, 구분된 클릭 영역과 키보드 안내를 추가했다. 100%·150% 배율과 한글·공백이 있는 배포 경로를 가정한 렌더링에서 표시를 확인했다. 네이티브 선택창 동작을 유지하며 다른 선택란에는 이 스타일을 적용하지 않는다.

`scripts/verify_source.py --output verification/embedded-login-production/final-source-checks-05`에서 pytest **2,082 통과·1 건너뜀**, Node **7 통과**를 확인했다. 임시 웹 프로필 유지의 실제 합성 WebEngine 검사와 콜백 HTML의 실제 loopback 응답 검사도 포함한다. Ruff·의존성·문서 14개와 로컬 링크 101개 검사도 통과했다. 소스 126개 파일의 식별자는 `18f7866e66d249979d851f113a290bf225579483ad6ea6695d8e909c9701c487`이다.

독립 검토에서 외부 키 페이지를 열고도 이전 내장 콘솔이 남는 경우를 재현했다. 외부 실행 성공 후에만 기존 내장 창을 정리하고 실패 시 보존하도록 수정한 뒤 재검사를 통과했다. 콜백 페이지는 데스크톱과 390px 화면에서 직접 렌더링해 확인했으며, 개인정보·쿼리 반영 없이 정적 스타일 hash만 허용한다. 이 소스의 새 실행본과 실제 계정 검증은 별도 판정한다.

화살표 표시까지 포함한 최종 소스 검사는 `final-source-checks-06`에서 pytest **2,082 통과·1 건너뜀**, Node **7 통과**였다. 소스·리소스 127개 파일 식별자는 `70f42bbf9abd59d23ab44de65f0b058a5c0fda5464494bccb8f907fdb5115edb`이며, 해당 선택란의 독립 검토도 통과했다. 실제 계정·추론 성공에 대한 미검증 범위는 그대로 구분한다.

## 연결 상태 확인·분석별 AI 선택 후속 작업

연결된 제공자를 눌렀을 때 새 로그인이나 키 발급을 다시 시작하지 않도록, 모든 제공자의 주 버튼을 읽기 전용 **연결 상태 확인**으로 정리한다. 진행 중에는 **연결 중단**으로 작업을 취소하고, 연결된 뒤에는 **연결 해제**를 표시한다. 프로그램 비교에서는 준비된 연결·모델 하나를 고르고, 이번 실행의 설정 사본에 고정한다. 저장된 기본 프로필·역할별 연결은 바꾸지 않는다.

이전에는 연결 여부와 기본 분석 AI 선택이 화면에서 충분히 구분되지 않았다. 정상 앱 데이터 점검에서는 ChatGPT 인증·외부 앱 사용 권한·기본 응답·JSON·보호된 검사 기록이 확인됐지만 도구 호출 검사는 통과하지 않았고, 기본 AI도 ChatGPT가 아니었다. 후속 Gemini 점검에서는 두 API 키 연결의 실제 응답 기록과 보호 저장을 확인했으며 그중 하나가 기본이었다. 반복 연결로 생긴 기존 항목은 삭제하거나 합치지 않았다. 연결 준비와 이번 비교의 선택을 분리한 이유다.

콜백 페이지에는 외부 앱 사용 권한이 필요하다는 일반 안내를 제공한다. 무료 계정에서 권한 제한이 나오면 지원되는 플랜의 계정이나 다른 AI를 선택하게 하며, 정적 페이지에서 사용자의 실제 플랜을 추정하지 않는다. 확인된 서버 오류 코드만 인증 단계의 권한 안내로 연결한다. `invalid_grant`, 앞선 점검용 저장소의 인증 부재, 사용자의 무료 계정 권한 제한, 이후 정상 저장소의 연결 확인은 서로 다른 시점·단계의 기록이다.

| 검토했지만 이번에 하지 않은 일 | 이유와 재검토 조건 |
| --- | --- |
| 연결된 모든 AI에 같은 분석을 자동 병렬 요청 | 제공자마다 비용·할당량·기능이 다르다. 개별 동의·예산·취소·부분 실패·결과 보관을 먼저 설계해야 하므로 [ADR-0007](0007-single-ai-per-analysis.md)에 보류한다. |
| 실패한 AI를 다른 계정으로 자동 대체 | 요청 대상과 전송 동의·예산이 달라진다. 사용자가 별도 실행에서 선택한다. |
| 비교 화면 선택으로 전역 기본 AI 변경 | 이번 비교의 선택과 저장된 기본값을 분리하기 위해 실행별 설정 사본을 사용한다. |

### 최종 검사·배포에서 확정할 항목
